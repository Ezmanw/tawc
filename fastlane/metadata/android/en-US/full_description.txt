TAWC allows you to install a normal Linux distro on your phone, and run Linux applications. Both CLI and graphical programs are supported. Graphical apps may use X11 or Wayland and may be hardware accelerated in either case.

No root required: tawcroot, a faster alternative to proot, provides an environment like standard desktop Linux to programs without needing elevated Android privileges.

Android integration: Linux apps appear alongside Android apps in the Android app switcher. Touch support, Android keyboard support, clipboard bridging and home screen shortcuts integrate Linux programs into Android, no separate Linux desktop needed.

Hardware acceleration: for now, only the graphics APIs supported by the device. This usually means GLES and Vulkan. This is good enough for many programs, but some require desktop GL which is generally unsupported. Apps that don't work can be changed to use CPU graphics (slower, but wider compatibility) by editing their launcher shortcut.

Remote access: SSH into your installed Linux distros via local network or an internet relay. sshyeet.com (or any compatible server) can be used as a relay. The remote access SSH server only runs when explicitly enabled.
